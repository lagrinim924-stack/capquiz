# CapQuiz 🌍

An interactive command-line quiz application with 190+ questions about world capitals.

## Features

- 190+ multiple-choice questions covering capitals from around the world
- Random question order each session
- Random option order each session
- Choose how many questions to answer per round
- Case-insensitive answer checking
- Score calculation at the end

## Requirements

- Python 3.x

## Usage

```bash
python CapQuiz.py
